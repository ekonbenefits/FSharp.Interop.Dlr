# Benchmarks

Generated by `Benchmarks/bench.sh docs` (BenchmarkDotNet, short job). Every `dlr { }` is bound and
compiled during warm-up, so a cell is the steady-state cost of one call and what it allocates.
The same operation is done each way it can be: statically, through cached reflection, with
FSharp.Interop.Dynamic 6.0, as C# `dynamic` (the same Microsoft.CSharp binders, the compiler's
own call sites), and in a `dlr { }`. A dash means that column has no form for the row here, or
the row is not the same operation there — nothing more.

BenchmarkDotNet v0.15.8, macOS 27.0 (26A428) [Darwin 27.0.0]  
Apple M1 Pro, 1 CPU, 10 logical and 10 physical cores  
.NET SDK 10.0.400
